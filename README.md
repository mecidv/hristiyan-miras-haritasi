# Türkiye İnanç Turizmi Yaşayan Envanter Projesi

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24338235.svg)](https://doi.org/10.5281/zenodo.24338235)

*Religious Tourism of Türkiye: Living Inventory Project* · https://envanter.mecidvergul.com

Türkiye’nin 76 ilindeki 622 kilise, manastır ve şapel kaydını kültürel miras olarak bir araya getiren interaktif envanter haritası. Veriler, A. Mecid Vergül’ün *Türkiye’de Hristiyan Kültür Mirasının Haritalandırılması* (Yüksek Lisans Tezi, Kastamonu Üniversitesi, 2024) çalışmasına dayanır.

- `index.html`: Proje tanıtımı, ekip, atıf
- `harita.html`: İnteraktif harita, filtreler, ziyaretçi geribildirimi
